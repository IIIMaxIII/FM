# FM Stats — ForgeMiner stats hook for HiveOS

Кастомный stats-скрипт для майнера **ForgeMiner**, который передаёт статистику
в веб-морду HiveOS, **парсит найденные блоки и реджекты**
---

## ✨ Возможности

- 📊 Передача стандартной статистики в дашборд HiveOS
  (хешрейт, температуры, вентиляторы, аптайм, шары, алгоритм).
- 🧱 **Парсинг найденных блоков** из TUI майнера через `screen hardcopy`.
- ♻️ **Накопительный счётчик блоков** за сессию рига — не сбрасывается
  при рестарте майнера.
- ❌ Отображение **реджектов и stale-шар** в поле `ar`.

---

## 🧱 Отображение блоков в веб-морде

Поле **`Blocks`** в веб-интерфейсе HiveOS появляется **только после того,
как майнер найдёт первый блок**.

- До первого блока строка `| Blocks: N` **не отображается** вообще.
- После первого найденного блока счётчик начинает показываться в поле `ver`
  в виде: `ForgeMiner vX.X.X | Blocks: N`.
- Счётчик **накапливается за сессию рига**: при рестарте майнера он
  не сбрасывается в 0, а продолжает расти.
- При **перезагрузке рига** счётчик **обнуляется** — состояние хранится
  в `/dev/shm` (tmpfs, RAM), который очищается при ребуте.

---

## 🔧 Установка

Скачать скрипт сразу в каталог майнера, присвоить права и заменить старый файл:

```bash
wget -O /hive/miners/custom/ForgeMiner/h-stats.sh https://github.com/IIIMaxIII/FM/raw/refs/heads/main/h-stats.sh && sudo chmod 755 /hive/miners/custom/ForgeMiner/h-stats.sh
```
